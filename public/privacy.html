Family Board – Privacy Policy

Last updated: September 24, 2026

What Family Board is

Family Board is a personal, non-commercial family dashboard: a calendar, chores list, notes, weather and photo screensaver shown on a wall-mounted tablet in one household. It is built and run by one individual for their own family. It is not offered to the public, there are no user sign-ups, and it is not sold or monetized in any way.

Google data the app accesses

The app connects to a single Google account belonging to the household, with these OAuth scopes:

  • https://www.googleapis.com/auth/calendar — Google Calendar. Used to read events from the household's calendars so they can be displayed, and to create, edit and delete events when someone does so from the touchscreen. The app also reads the calendar list to check whether each calendar can be written to.
  • https://www.googleapis.com/auth/drive.readonly — Google Drive (read-only). Used only to list and display image files from a folder the household chooses, for the photo screensaver and family member pictures. The app cannot change or delete anything in Drive.

No other Google APIs or account information (such as your profile or contacts) are used.

How data is handled

  • Google credentials stay on the server. The Google refresh token is stored only as an encrypted environment variable in the app's Vercel hosting account. It is shown once to the owner during the initial setup so it can be saved there, and it is never sent to or stored on the tablet. The server uses it to get short-lived access tokens, which are kept only in memory.
  • Data is cached only on the device. Calendar events, notes, chores, family member names and pictures, settings, the weather location and the list of screensaver photos are cached in the tablet's browser storage (localStorage) so the board keeps working offline. Recently shown photos may also sit briefly (up to about an hour) in the browser's normal cache.
  • No server-side database. The server passes requests through to Google and returns the results. It does not store or log calendar events, photos or other content. The only information it keeps is short-lived, in memory: the access token and per-IP request counters used to limit abuse.
  • No analytics, ads or tracking. There are no analytics tools, ad networks, tracking pixels or error-reporting services.

Sharing and third parties

User data is not sold, shared, rented or transferred to anyone. It is not used for advertising, and it is not used to train AI or machine-learning models. The only outside services involved are infrastructure the app needs to work:

  • Google APIs (Calendar, Drive and sign-in), where the data already lives.
  • Vercel, which hosts the website and the server functions.
  • Open-Meteo, a free weather service. The tablet sends it only the latitude and longitude set in the board's settings. No Google data is sent.
  • Google Fonts, which serves the board's typeface. Like any web font, this request reveals the device's IP address and browser type to Google.

Google API Services User Data Policy

The app's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Cached data stays on the tablet until it is cleared, either by resetting the app or by clearing the browser's website data.
  • You can revoke the app's access to your Google account at any time at https://myaccount.google.com/permissions.
  • Removing the refresh token from the Vercel environment ends all of the app's access to Google data immediately.
